# Model attribution

The D19 mesh used by **Curse of the D19** is adapted from **dAny - parametric Any Number Dice (d19 d7 d13 d21 d20 d9 d100)** by **dunaevai135**.

Original model: https://www.printables.com/model/769247-dany-parametric-any-number-dice-d19-d7-d13-d21-d20

The source model is published under **CC BY-SA**. The adapted D19 mesh files in this repository remain under that same CC BY-SA license. The Foundry VTT module code is separately licensed under MIT.

For this adaptation, the uploaded `d19_deep` STL was centered, normalized to a longest dimension of 2.0 units, and exported as `models/d19.glb`. No changes were made to the modeled 1-19 engravings beyond geometric conversion/normalization.
