# D19 model

The runtime D19 asset is adapted from **dAny - parametric Any Number Dice (d19 d7 d13 d21 d20 d9 d100)** by **dunaevai135**.

Original model: https://www.printables.com/model/769247-dany-parametric-any-number-dice-d19-d7-d13-d21-d20

The original model is published under **CC BY-SA**. The adapted D19 mesh remains under the same CC BY-SA license. See `../ATTRIBUTION.md`.

For v0.2.0 the selected source was the deep-engraved D19 STL supplied by the project owner. It was centered and normalized for use as a Foundry/Dice So Nice test asset. The source STL is watertight and contains 20,073 vertices and 40,146 triangles before conversion.
